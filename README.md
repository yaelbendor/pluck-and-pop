# Pluck & Pop

A cozy little skin spa game for phones. Use two fingers: pinch a bump to pop it, pinch a hair and pull it out.

Play: https://yaelbendor.github.io/pluck-and-pop/

- Relax mode: pimples, blackheads, ingrown hairs, hair clusters and long hairs, then spread the glow cream
- Rush hour: pamper as many clients as you can in 60 seconds
- Sticker book: collect every client, unlock new friends and towel patterns
- Add it to your home screen to play it like an app (works offline)
